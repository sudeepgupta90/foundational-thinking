# foundational-thinking

Two agent skills, codified from classical method:

- **`socratic-inquiry`** — use when a request turns on an abstract quality word (reliable,
  scalable, clean, better...) that nobody has defined, when a cause is asserted rather than
  demonstrated, or when a question presupposes its own answer. Not for choosing between
  named options. Dissolves an ill-formed question into a well-formed one.
- **`scholastic-disputation`** — use when a choice between two or more named options is
  owed, including when their success criteria are still vague; also when conflicting
  recommendations need adjudicating, when your own call is challenged, or when a decision
  must be written down and defended later. Builds a determination that survived its
  objections.

Invoke either by name; the runtime loads the body on demand. Full skill definitions are in
`skills/`, and the source material plus the routing logic between the two methods is in
`principles/README.md` — both relative to the foundational-thinking repo root, which is not
necessarily the directory this file was loaded into.
